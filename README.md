# Street Launcher — сайт

Статический сайт лаунчера. Открывается без сборки и без сервера: это обычные
`index.html`, `styles.css` и `app.js`. Для корректной работы шрифтов, скриншотов
и скачиваний лучше запускать через локальный HTTP-сервер.

## Локальный запуск

```powershell
cd C:\Users\zkazi\StreetLauncher\website
python -m http.server 4173
```

Откройте <http://127.0.0.1:4173/>.

Можно открыть и напрямую `website/index.html`, но некоторые браузеры ограничивают
загрузку локальных ресурсов и `download`-ссылки.

## Структура

| Путь | Что внутри |
| --- | --- |
| `index.html` | Вся разметка: hero, скриншоты, возможности, темы, FAQ, скачивание |
| `styles.css` | Тёмная неоновая тема, стекло, адаптивность, анимации |
| `app.js` | Панель тем, пресеты, свои цвета, фон, стекло, радиус, шум, localStorage |
| `assets/icon.png` | Иконка лаунчера |
| `assets/logo.svg` | Логотип для шапки |
| `assets/shots/` | Скриншоты Home / Friends / Modpacks из версии 1.1.0 |
| `downloads/` | Установщик и портативная сборка 1.1.0 |

## Смена темы

Кнопка **«Тема»** в правом верхнем углу открывает панель:

- пресеты **Neon Red**, **Ice**, **Violet**, **Mono**;
- два акцентных цвета;
- цвет и яркость фона;
- прозрачность стекла;
- радиус карточек;
- включение/выключение градиента и шума.

Выбор сохраняется в `localStorage` и применяется при следующем открытии. Кнопка
«Сбросить» возвращает Neon Red.

## Обновление контента

Скриншоты лежат в `assets/shots/home.png`, `friends.png`, `modpacks.png`.
После новой сборки лаунчера замените их и при необходимости обновите подписи в
`index.html`.

Ссылки на скачивание указывают на `downloads/StreetLauncher-Setup-1.1.0.exe` и
`downloads/StreetLauncher-Portable-1.1.0.exe`. При выпуске новой версии:

1. положите новые exe в `downloads/`;
2. обновите версию и размер в `index.html`;
3. обновите блок «Street Launcher 1.1.0» и ссылки.

## Публикация

Сайт можно выложить на любой статический хостинг (GitHub Pages, Netlify, Vercel,
Cloudflare Pages, обычный nginx). Папка `downloads/` весит около 220 МБ — если
хостинг не принимает такие файлы, загрузите exe отдельно и замените ссылки на
прямые HTTPS-URL. Не забудьте, что для автообновления лаунчера нужен отдельный
подписанный манифест (см. `../README.md`, раздел «Автообновление»).
